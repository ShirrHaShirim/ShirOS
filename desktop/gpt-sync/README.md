# ShirOS 对话同步扩展 · 0.7.4.1

本次修正记忆标题。新会话使用 `对话｜原会话主题｜完整对话`，第三段与正文的 `【记录类型】完整对话` 一致。原标题仍保留在采集授权中；来源网站和编号不作为主题前缀。原标题已经是完整三段式时保留其领域及主题，不重复套用前缀。已有会话继续按平台和会话编号更新原记忆，保留人工整理的正式标题。扩展弹窗显示拟生成标题，服务端执行最终隐私检查。

在 `chrome://extensions` 重新加载原目录的扩展，再刷新网页即可。ShirOS 主程序当前为 v0.7.6；扩展组件版本为 0.7.4.1。

在 Edge/Chrome 中加载此文件夹。升级时先重新加载扩展，再刷新对话网页。ShirOS「设置 → 插件与对话同步」可授权单个会话或网页平台批量范围；名称留空会自动使用原对话标题。在扩展保存配对并点击开始后才采集。默认自动滚动历史，之后持续同步。

「批量导入对话」包括「最近」过滤处理和已发现项目目录扫描，另开后台标签页逐条保存，支持停止与进度，连续两个识别失败时暂停。只覆盖网页能加载出的目录；完整导出包可在 ShirOS 文件库导入。

采集器覆盖同源 iframe、开放的 Shadow DOM、通用消息节点和延迟加载。开始前核对服务端授权。「复制识别诊断」只含结构标记、来源与数量，不含正文。ShirOS 中已撤销的授权记录可删除或恢复显示，导入内容保留。

支持 ChatGPT、DeepSeek 网页，以及当前标签页权限允许的本机 DSH 页面。正文进入一般记忆库；已取得的附件原件进入文件库并建立关联。安装扩展后默认不采集。

完整安装说明、原生客户端接入与限制见项目 `docs/conversation-sync-v073.md`。不在此文件夹保存个人配对 JSON、密钥、聊天正文或附件。

0.7.4 支持从 ChatGPT 首页直接批量导入，无需先点开某个对话。插件自动展开侧栏、读取多个滚动列表，合并“项目”筛选两种状态，读取可见的更多列表与搜索目录，再遍历页面提供的项目及目录链接。计数表示“已发现”，不代表账号总数；未读完的目录会明确提示。页面未提供的归档等记录请使用官方导出包导入。

一个会话对应一条记忆，后续更新同一条记录；单条记忆上限 1,000 万字符。新增授权可重新采集曾被删除或拒绝的对话，旧状态保留。首次需在 ShirOS 授权平台批量采集并保存配对；升级后重新加载扩展并刷新网页。网站权限仅限 ChatGPT、DeepSeek 和本机 ShirOS；若 Chrome 提示新增网站权限，请允许所需平台。开始前仍须通过 ShirOS 的授权检查。

服务端非 JSON 错误现在显示 HTTP 状态并有限重试；持续存储错误暂停批量，已保存记录保留。页面采集器未连接时，自动重新注入并恢复；无法取得网站权限时提示检查扩展权限。

0.7.4 适配 2026 年 10 月的新 ChatGPT 消息标记，分别识别提问和回答。自动选择对话滚动容器，确认顶部历史稳定后再逐段读到末尾，完整读取后分批保存；单独显示提问数、回答数和阶段。仅采到提问时明确提示未完成。对话继续新增问答后，再采集会更新原记忆并保留修订，不新增第二条同会话记忆。

批量目录操作在独立后台标签页完成；兼容侧栏未使用 nav/aside 的布局。诊断同时包含 manifest、popup、worker、页面采集器版本，便于排查混用旧代码。

已有有效授权无需再次授权。若丢失配对信息，在 ShirOS 设置中找到该授权，选择「重新生成配对」，将新信息粘贴到扩展的「连接 ShirOS」；此操作使旧配对失效，保留原会话记忆和授权范围。

0.7.4 修复启动阶段未加载页面信息或旧配对记录无效时的空值异常；点击开始时重新核对当前页面。适配整段会话共用一个外层容器的布局，按提问气泡与回答正文拆分，排除时间和复制控件。滚动区域持续不动会停止并显示诊断，不继续等待或标记完整。弹窗采用紧凑卡片，分别显示问答计数、批量进度，连接和诊断默认折叠。

自动滚动支持正向与负坐标的反向容器。获准开始后检测实际可移动方向，统一顶部和末尾判断，并按页面中的显示顺序归并消息；诊断增加 `reversed`、规范化 `position` 和 `flex_direction`。页面位置为 0 时不再直接认定处于顶部。目录滚动也使用这一坐标处理。

遇到禁止保存的消息，不再回滚整段会话：该消息的原文及附件不写入消息库，改为明确的未收录占位，其他消息继续提交，整段保留待审。插件分别显示「已保存到 ShirOS」与「已提交 ShirOS 待审」，并标明未收录数量。人工审核只批准可保存的内容，不能恢复被省略的原文。升级保留现有配对。
