# ShirOS v0.5.0 使用说明书

## 安装与首次启动

适用于 Windows 10/11 x64。安装前确认系统已安装 Microsoft Edge WebView2 Runtime；一般随 Edge 提供。缺少时从微软官方下载并安装：https://developer.microsoft.com/microsoft-edge/webview2/

- `ShirOS-0.5.0-full-Setup.exe`：记忆、审核、文件库和音乐库。
- `ShirOS-0.5.0-core-Setup.exe`：记忆、审核、文件库，不开放音乐功能。

双击安装包，选择安装位置，再从桌面快捷方式启动。无需 Python、Docker 或另装 PostgreSQL。首次初始化可能需要数十秒。安装包未做商业代码签名；可用 SHA256SUMS.txt 核对文件完整性。

安装目录附带 `prompt.txt`。朋友安装好后，可以把它拖进 Codex/Harness，让代理定位安装目录、检查 WebView2、运行独立空白验收，再启动桌面程序。这个提示词部署桌面端；本安装包尚不自动注册 Codex/Harness 的 MCP 工具连接。

两个版本分别使用 `%LOCALAPPDATA%\ShirOS-Desktop\full` 与 `core` 保存数据；彼此独立，与开发版数据无关。首次安装没有记忆、待审记录、文件或唱片。更新安装保留已有用户数据，因而在已经使用过的电脑上重装不会清空资料。卸载也保留资料。

请正常关闭窗口，等待数据库结束。重复打开同版本会提示已有实例。首次运行可能需要允许程序启动本地服务；数据库和界面都只监听 127.0.0.1。

## 记忆与审核

左侧「记忆」查看正式内容；「展开全部」浏览标签树和按添加日期排列的内容。可以选「无标签」，记忆也可不添加标签。

「添加记忆」支持文本、Markdown、JSON、CSV 的预览和提交。检查待审队列，编辑内容后批准或拒绝。批准前不会进入正式检索。来源、证据等级与正文分别保留；审核不会自动把模型推测变为已验证事实。

## 导出 Markdown

点击记忆页面右上方「导出全部 .md」，获得 UTF-8 Markdown 文件。选择记忆后点击「导出此记忆 .md」可单独导出。包含当前正文、标题、稳定 ID、修订、时间、标签、来源记录与证据元数据。隐藏、撤销以及历史修订不包含在正常导出内；Markdown 导出不等于可完整恢复数据库的备份。

## 文件库

点击「文件库」→「导入文件」，可多选任意类型文件，单文件最大 50 MB。文件按原始字节保存，可以按文件名搜索、分页下载或删除。文件不会执行，也不会自动成为记忆；若要提炼记忆，请人工复制相关文本到添加记忆并审核。

删除文件无法在软件内恢复，请先下载需要保留的原件。当前不提供目录分类、OCR、全文索引或文件预览。大量视频或其他大文件建议在专用文件存储中保存。

## 完整 GPT 对话导入

在 ChatGPT 的数据控制设置申请官方数据导出。得到导出文件后，在文件库点击「导入 GPT 对话」，选择 `conversations.json` 或含有该文件的官方 ZIP。每次单文件最大 50 MB；每批最多 1000 段对话，转换结果总计最多 100 MB。过大的导出可拆分 JSON 数组后分批导入。

ShirOS 保存原始文件，并为每段对话生成 Markdown，保留全部文本消息节点、父子分支关系、消息时间和原始元数据。附件引用和工具结构仍保存在原始导出中；并不自动下载附件的远端原件。消息节点按原始 JSON 顺序展示，父子 ID 用于辨认分支，并非只导入当前分支。再次手工导入会增加新文件，不会覆盖第一次存档。

这些对话进入文件库，不会自动改写正式记忆，也不会自动调用 GPT、提炼内容或消耗 API 费用。

## 持续同步 GPT 网页（试验功能）

安装目录的 `GPT-Sync` 是 Chrome/Edge 的未打包扩展。打开浏览器扩展管理页面，启用开发者模式，点击「加载已解压的扩展程序」，选择该目录。

打开 ChatGPT 对话页，点击扩展图标开始同步；图标显示 ON。每 20 秒有变化时，扩展将快照写入默认下载目录 `ShirOS-GPT` 子文件夹。桌面端运行期间每 5 秒读取该文件夹更新文件库，同一对话更新同一个文件。再次点击停止；换到另一段对话会停止采集，需要重新开启。

浏览器的默认下载位置须为 `%USERPROFILE%\Downloads`，否则桌面端无法自动找到。下载前询问位置的设置可能中断自动快照。同步仅包括网页已加载的消息和当前分支，长对话、折叠内容、附件、其他分支可能不完整；完整存档请使用官方导出。不要把网页快照当作完整账号备份。

扩展不读取 Cookie、不保存登录凭证、不访问 ChatGPT 隐藏接口。默认关闭，仅在主动开启的页面采集。此功能尚未在真实 ChatGPT 长对话中验证，网站结构变化可能使它停止工作。

## 音乐库（full 版）

创建作品、录音、专辑、人物或乐团；可以不加标签。Genre 目录与私人标签、记忆库标签独立。可上传 JPEG、PNG、WebP 封面和头像，单张最大 8 MB；系统会移除图片元数据并规范化为 WebP。

可录入评分和评论、管理想听/在听/听过，导入豆瓣 CSV/JSON、保存外部音源链接与手工聆听事件。精选需要当前五星，常用由人工管理。外部链接只打开相应平台，不代表 ShirOS 已播放音乐或观测到聆听。

## 主题与数据备份

顶部「配色」可选择羊皮纸、苔庭、青金、暮紫、石墨五种主题。颜色与语言设置保存在本机界面缓存。

备份前关闭窗口，确认 ShirOS 的本地 PostgreSQL 已停止，再复制整个版本数据目录到安全位置。还原时关闭程序，恢复同版本完整目录，使用同一 Windows 用户打开。复制数据库目录时服务仍运行可能导致不可用备份。Markdown 和文件下载适合迁移内容，不包含审核与数据库全部历史。

桌面版不自动连接开发环境的 MCP 隧道，也不继承任何 GPT 或 Codex 登录、密钥、身份授权。程序需要的本地数据库随机凭证首次启动生成，仅存于该 Windows 用户的数据目录。

## 常见问题

- 启动失败：检查 WebView2、剩余空间、安装文件是否完整及数据目录权限。
- 启动较慢：首次数据库初始化和迁移会有延迟，避免同时打开多个实例。
- 文件导入失败：检查大小上限；GPT 专用按钮只接受符合结构的对话导出。
- 页面被锁定：正常关闭并重启桌面程序，不要复制其他程序的会话令牌。
- core 版没有音乐入口：这是版本区别，安装 full 版后使用其独立数据目录。

## 开发者构建

运行 `uv sync --group desktop`，准备 PostgreSQL 16 x64 + pgvector 的便携运行时及官方 Inno Setup 编译器，再运行：

```powershell
uv run --group desktop python scripts/build_desktop.py --postgres PATH_TO_LIBRARY --iscc PATH_TO_ISCC
```

输出在 `dist/desktop`。构建只收集程序、迁移和指定运行时；每个版本生成带哈希的文件清单。安装包发布前必须在新的数据目录运行 `ShirOS.exe --smoke-test --data-dir ABSOLUTE_EMPTY_PATH`，核验 `smoke-result.json` 的各内容表计数为零。
