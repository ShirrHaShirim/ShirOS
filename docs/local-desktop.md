# 本机 ShirOS 桌面工作台

双击桌面或开始菜单的「ShirOS - 我的工作台」。它连接 `D:\Shir OS` 的现有服务和数据库，不使用发行安装包的空白数据库，也无需迁移记忆或重新配置 MCP。

## 后台模式

默认开启。点击窗口右上角关闭按钮后，窗口隐藏到系统托盘。双击托盘图标或再次双击快捷方式可恢复同一个窗口。托盘图标可能位于 Windows 的隐藏图标菜单中。

左下角「设置」→「窗口与后台」，切换「关闭窗口后在后台运行」。托盘菜单也可切换。选择会保存在本机，重启继续有效。

关闭后台模式后，点击窗口关闭按钮会退出桌面程序并移除托盘图标。托盘菜单的「退出桌面程序」在任何模式下都能退出。

这里的后台开关控制桌面程序。现有数据库、MCP 和共享接口是独立服务，退出桌面程序不会停止它们，以便 Codex、Harness 等继续访问同一份记忆。

图标源文件位于 `desktop/shiros-icon.svg`，Windows 多尺寸图标为 `desktop/shiros-icon.ico`。本机偏好位于 `.local/desktop-settings.json`，不应上传。

## v0.6.0 配色保存

左下角「设置」统一提供颜色主题、界面语言、后台模式与全屏选项。主题名称为白色、暖白、绿色、蓝色、紫色、深色。配色按当前用户保存在 ShirOS 数据库，完整退出再打开也会恢复；不依赖浏览窗口是否保留缓存或服务端口是否变化。桌面 WebView 使用 `.local/desktop-webview` 专用本机目录。

## 全屏与窗口操作

桌面工作台默认全屏，移除系统标题栏和菜单栏。「设置」中的全屏开关或 F11 可切换，选择会保存在本机。顶部导航提供最小化、最大化/还原和关闭窗口按钮；拖动导航空白区域可移动窗口，双击可最大化/还原。后台开启时关闭窗口仍收进托盘。

知识维护页显示名称为 L0「核心原则」、L1「领域总结」、L2「详细记录」。底层层级编号与已有记录不变。

最大化保留系统任务栏，全屏占满显示器。普通窗口可拖拽四边与四角缩放。最小化和恢复使用 Windows 原生过渡，遵循系统动画设置。
