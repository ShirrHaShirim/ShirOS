# Music Entry Rules — 0.7.18

本文件是当前规范，旧工作报告只描述当时状态。数据整理不能改变客户端权限、自动批准敏感候选或虚构音乐事实。

## 身份和证据

- Work 是创作，Recording 是演绎录音，Release 是发行版本，Track 是发行内曲目位置。
- 完整交响曲、协奏曲或奏鸣曲通常保持一个 Work，不能因多乐章分轨机械拆作品。
- 专辑整体可为 Work，歌曲作为其子 Work；发行、再版和目录号不创建新的创作身份。
- 人物、组合、机构通过明确关系关联，人员分工按实际演出，不把唱片全集人员赋给每条录音。
- 录制日期与发行日期分开；未知保持未知，同名不自动合并。
- 修改保留稳定 ID、修订、历史评价、来源、原图与审计；曲库不自动成为普通记忆。

## 浏览组织

- 使用封面卡片形式的嵌套作品集；允许 `folder` 浏览组和 `collection` 创作集合。
- 顶层可直接展示如 Beethoven: Chamber Music，内部展示 Early String Quartets、Late String Quartets、Violin Sonatas 等。
- 不增加作曲家/类别/作品侧栏树，作曲家库继续独立。
- Genre 与作品集独立，不用分类树重复作品集组织。
- 每个作品和作品集使用自己的图片；用户设计优先，禁止自动继承父作品封面或用单部作品的谱子代表全部子作品。

## 完整覆盖与连续范围

- Recording 完整覆盖某 Work，才关联该 Work；完整合集可同时关联其覆盖的子作品集。
- Work → Recording → Release 连续进入时，只显示起始 Work 所对应曲目，允许“显示全部”。
- Recording 具有“作品”入口；专辑歌曲汇总到对应专辑 Work，连续进入时只显示实际演奏歌曲。
- 范围为临时导航状态，Back 可恢复；独立搜索、排序、筛选、库导航和修改清除继承。
- 完整详情、权威关系和导出不因范围改变，未知定位不能假装已完整识别。
- 范围名称、数量和解除操作使用紧凑提示行，不占用独立大型框。

## 录音与评价

- 子录音只按明确关系、用户操作和证据创建，不按所有音轨自动生成。
- 同一录音可复用到多个发行；整张录音与发行评价独立。
- 子录音不显示新的评分入口；已有评价历史保存，不用于父录音平均分。
- 收藏、评分、评价、聆听与外部音源各自保留语义，打开链接不是播放。

## 图片维护

- 保留已有图片，补图核对同一发行版本、来源与归属；找不到明确版本则留空。
- 下载被拒绝或挑战时停止该来源，不绕过访问限制。
- 应用 manifest 校验 ID、revision、文件 hash 和当前缺图状态，使用标准图片服务并记录 attribution。
- 修改前备份，在独立副本验证；图像维护不得覆盖标题、人员、评分、曲目或关系。

具体模型与接口见 [音乐库](music-library.md)。
