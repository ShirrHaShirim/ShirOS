# Music Library — 0.7.18

音乐库是独立权威领域，复用 scope、权限、来源和审计；不会将音乐档案自动复制为普通 Memory。

## 实体

| 对象 | 含义 | 独立性 |
| --- | --- | --- |
| Work | 创作身份，包括完整古典作品、专辑作品、歌曲、collection 与浏览 folder | 不等于具体演出或唱片 |
| Recording | 一次演绎及录制形成的声音，可关联多部作品 | 不等于发行；可无正式发行 |
| Release | 具体 CD、黑胶、数字或再版发行 | 独立日期、厂牌、封面与目录号 |
| Track | 发行内 disc/position、曲名、时长与作品/录音关系 | 不机械生成新作品或录音 |
| Person / Group / Organization | 人物、组合与机构档案 | 实际关系派生身份；关联分工有具体依据 |

跨作品、录音、发行的同名记录不按名称自动合并。未知人员、日期、位置或时长保留未知，不用发行日期替代录制日期。谱子、艺术设计、照片与唱片封面各自有来源，不能因为父子关系批量复用图片。

## 作品与录音层级

显式 `parent_work` 支持封面卡片嵌套。`work_form=album` 是专辑创作，`collection` 是作品集合，`folder` 是个人浏览组织；Genre 与作品集保持独立。

根页直接展示顶层作品集和独立作品，不再增加“作曲家 → 类别 → 作品”侧栏。已有作曲家档案另行提供其作品入口。每层使用自己的封面，缺图用占位，不能自动继承父封面。

Recording 对 Work 的关联要求完整覆盖该 Work。作品集关联完整覆盖其定义范围的录音；只包含部分成员的录音留在相应子作品上。显式子录音通过 `parent_recording` 组织，可在多个发行中复用，按需分页；不会自动按全部 Track 创建子录音。子录音不提供新的评分入口，历史评价仍保留。

## 临时浏览范围

1. 从作品进入完整录音，保留当前作品范围。
2. 连续进入发行，仅显示该范围实际对应的曲目，紧凑行显示名称和 visible/total。
3. “显示全部”解除当前范围；Back 可恢复先前范围。
4. 录音“作品”入口列出所含作品，专辑歌曲汇总到专辑作品；连续进入专辑作品时只展示实际演奏歌曲。
5. 独立搜索、排序、分类筛选、库导航或成功修改清除继承范围。

服务端 `browse-context` 校验对象、关系和 scope，返回有序 track ID。未知定位明确保留，不能静默截断为已知部分。范围仅影响展示；完整详情、关系与导出不改变。

## 关系、分类与评价

关联携带角色、具体演奏分工、来源和必要日期。Work 大类与 Genre 描述创作，Recording/Release 按实际作品关系聚合只读分类。人物身份不能由未建立的关联推断。音乐私人标签与记忆标签分开。

Recording/Release 的个人评价保存修订，保留原五星或七星尺度，不自动重算旧分数。整张录音、子录音与发行评价不复制或平均。精选、常用、聆听状态与实际聆听事件分开；打开外部链接不等于播放。

## 图片

通过 `image-upload` 保存经过验证的图片和来源，`image-frame` 仅调整绑定当前 image ID 的位置与缩放，不改原图像素。替换图片采用新图片默认取景，旧引用按历史保留。API 读取保持认证。

批量补图使用经过人工/来源核对的 manifest、预期对象 revision 和文件 hash，走标准图片服务。已有封面保持原样；找不到同一版本时明确留空，不用模糊相似封面冒充。

## 接口

工作台通过 `POST /ui-api/music/{action}` 调用绑定身份的 MusicService。MCP 使用 `music_query` 与 `music_mutate`；写入需独立 `music_write`，不因 memory editor 权限自动获得。

核心动作包括 list/detail/stats/export、关系与档案栏目、browse-context、save、review、membership、listen、source、导入预览/提交、分类、图片和录音分组。精确 payload 以 [Pydantic 模型和 action 分派](../src/shiros/domains/music.py) 为准；不维护易失真的独立端点副本。

已有对象修改需当前 `id/revision`。冲突应重读，不静默覆盖。`shiros-music-1` 是领域 JSON 导出，不是数据库备份恢复格式。外部收藏 CSV/JSON 导入先预览，再显式提交；合成示例见 [CSV](music-import-example.csv)。

## 验证

集成测试覆盖权限、scope、修订、关系、分类、录音覆盖、子录音、评价历史、图片和浏览范围。浏览器回归验证用户路径与窄屏布局。专用测试库与个人运行库分开；本仓库不附带维护者的个人条目 ID 清单或曲库数据库。
